🚀 Key Features Implemented

📋 Document Extraction

Extract tender IDs, names, budgets, dates, contacts, organizations, locations, and scope of work

🤖 Machine Learning

ML models for improved extraction accuracy with confidence scoring and field-level training

📸 OCR Support

Automatic OCR for scanned PDFs with image preprocessing and multi-page support

⚡ Async Processing

Celery-based async tasks with periodic jobs (cleanup, reports, backups)

🔌 Webhooks

Event notifications with HMAC-SHA256 signing, retry logic, and event history

💾 Auto Backups

Automatic database backups (SQLite + PostgreSQL) with restore functionality

⚙️ Full Logging

Structured JSON logging, audit trails, request logging, and error tracking

🔒 Security

JWT authentication, API keys, password hashing, CORS, CSRF protection

📚 Batch Processing

Process multiple documents simultaneously with progress tracking

📤 How It Works

1️⃣ Upload a tender document (PDF, DOCX, etc.)

2️⃣ System extracts all relevant information

3️⃣ Results shown with confidence scores

4️⃣ Export to JSON or CSV

🔌 API Endpoints

POST /api/upload
Upload a document for extraction
POST /api/extract
Extract information from uploaded document
GET /api/extraction/{extraction_id}
Get extraction results
GET /api/uploads
List all uploads (paginated)
GET /api/extractions
List all extractions (paginated)
POST /api/export/{extraction_id}
Export extraction as JSON or CSV
DELETE /api/extraction/{extraction_id}
Delete an extraction
POST POST /api/users/register
Register new user (coming soon)
POST /api/users/login
User login (coming soon)
GET /api/admin/stats
Admin dashboard statistics (coming soon)
